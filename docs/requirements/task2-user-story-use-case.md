# Личный кабинет продавца

# User story

* "Как селлер, я хочу создавать и публиковать карточку товара через личный кабинет, чтобы мои товары стали доступны покупателям на маркетплейсе".

# User case

1. `Название` Публикация карточек товаров на маркетплейсе
2. `Акторы` Продавец
3. `Цель` Дать предпринимателю возможность публиковать карточки товаров через личный кабинет для запуска продаж на маркетплейсе.
4. `Предусловия` 
   1. Пользователь авторизован
   2. Подтверждён статус продавца (ИП\самозанятый\ООО)
5. `Сценарий` 
   1. Селлер открывает приложение или сайт.
   2. Система загружает и отображает главный экран.
   3. Продавец переходит в окно личного кабинета.
   4. Продавец нажимает на кнопку "Зарегистрировать новый товар".
   5. Система загружает и отображает форму регистрации нового товара
   6. Продавец заполняет обязательные поля формы: название, цена, описание, изображение, категория, артикул, количество на складе.
   7. Продавец нажимает на кнопку "Опубликовать товар".
   8. Система перенаправляет продавца на экран с уведомлением о запущенной проверке данных о товаре. На экране отображается статус проверки и внесенные в форму данные о товаре. Пользователю снова доступна публикация нового товара.
   9. После завершения проверки данных о товаре система обновляет статус на экране. Товар отображается как "опубликованный". Также система уведомляет продавца о завершении проверки уведомлением (push\email\sms). 
   10. На экране появляется ссылка для перехода к карточке товара. По ссылке отображается экран товара, предназначенный для покупателя.
   11. `Альтернативные пути` 
       1. Если данные, внесенные в форму, не прошли проверку, продавец получает уведомление с описанием причины.
       2. Если в процессе проверки формы регистрации товара продавец решает отменить публикацию или внести изменения в форму, ему доступна соответствующая кнопка в личном кабинете, завершающая процесс проверки со статусом "отмена".
   12. `Постусловия` Продавец опубликовал данные о своем товаре через личный кабинет, товар доступен к покупке всем пользователям маркетплейса.
